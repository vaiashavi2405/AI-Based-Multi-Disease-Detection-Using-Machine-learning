# 🩺 AI-Based Multi Disease Detection Using Machine Learning

An AI-powered healthcare application that predicts multiple diseases using Machine Learning algorithms. The system analyzes patient symptoms and medical data to provide automated disease prediction and healthcare suggestions through an interactive graphical user interface.

---

# 📖 Project Overview

AI-Based Multi Disease Detection Using Machine Learning is an intelligent healthcare system designed to assist in the early detection of diseases using Artificial Intelligence and Machine Learning techniques. The application processes patient symptoms and medical parameters to predict possible diseases and provide appropriate medical suggestions.

The system follows a complete machine learning pipeline including data collection, preprocessing, labeling, clustering, regression analysis, probability estimation, and classification. It utilizes K-Nearest Neighbor (KNN), Linear Regression, Hidden Markov Model (Deep Belief Network), and Decision Tree algorithms to improve prediction accuracy.

This project demonstrates the practical application of Artificial Intelligence in healthcare by providing an efficient and user-friendly disease prediction system.
